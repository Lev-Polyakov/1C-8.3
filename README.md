Конфигурация предназначена для автоматизации оперативного учета в розничной торговле. Основные сценарии использования:
*   Ведение номенклатуры, контрагентов и складов.
*   Оформление приходных и расходных документов (Поступление, Реализация).
*   Формирование отчетов для анализа продаж и остатков.
*   Разграничение прав доступа для сотрудников (администратор, руководитель, менеджер).

---

1. Структура конфигурации

1.1 Справочники
В конфигурации реализованы основные справочники для хранения условно-постоянной информации:
*   Номенклатура: иерархический справочник
*   Единицы измерения
*   Должности
*   Подразделения: иерархический справочник
*   Склады
*   Валюты
*   Банки
*   Расчетные счета
*   Контрагенты: иерархический справочник
*   Организации
*   Договоры
*   Номенклатура: иерархический справочник
*   Сотрудники
*   Пользователи
1.2 Перечисления:
*   Пол
*   Виды номенклатуры

1.3 Документы:
*   Заказ товаров
*   Поступление товаров и услуг
*   Счет на оплату
*   Реализация товаров
*   Реализация услуг
*   Реализация товаров и услуг
*   Регистрация цен
*   Выписка банка
В документах реализован автоматический расчет суммы: при выборе цены и количества сумма строки и итог документа пересчитываются автоматически (событие `ПриИзменении` в форме документа).
Также реализован подбор релевантных позиций: при заполнении табличной части «Товары» открывается форма подбора, в которой отображаются только те позиции, которые есть в наличии на выбранном складе (использование динамического списка с отбором по регистру остатков).
Ввод на основании. Например, из документа «Заказ товаров» можно создать документ «Поступление товаров и услуг» с автоматическим переносом данных (организация, контрагент, договор, номенклатура, цены, сумма документа).

1.4 Регистры
Для хранения оперативных данных и истории используются регистры сведений и накомления.
1.4.1 Регистры сведений:
*   Курсы валют
*   Цены номенклатуры
1.4.2 Регистры накопления:
*   Остатки материалов
*   Учет услуг
*   Взаиморасчеты
*   Стоимость материалов
*   Продажи

1.5 Отчеты
Отчеты реализованы с использованием Системы компоновки данных (СКД).
*   Список контрагентов
*   Список номенклатуры
*   Вхождение номенклатуры в документы
*   Номенклатура контрагента
*   Остатки номенклатуры
*   Продажа товаров

1.6 Журналы документов
*   Общий журнал
*   Торгово-закупочный журнал

		—   Поступление товаров и услуг
		—   Выписка банка

2.1.2   Подсистема «Продажи»:
	*   Документы продаж:
		—   Счет на оплату
		—   Реализация товаров
2.1.3 Подсистема «НСИ» (Нормативно-справочная информация):
	*   Общие формы:
		—   Организация
	*   Справочники:
		—   Единицы измерения
		—   Должности
		—   Подразделения
		—   Склады
		—   Валюты
		—   Банки
		—   Расчетные счета
		—   Контрагенты
		—   Организации
		—   Договоры
		—   Номенклатура
		—   Сотрудники
	*   Журналы документов:
		—   Общий журнал
	*   Регистры сведений:
		—   Курсы валют
2.1.4 Подсистема «Отчеты»:
	*   Отчеты:
		—   Список контрагентов
		—   Список номенклатуры
		—   Вхождение номенклатуры в документы
		—   Документы контрагентов
		—   Номенклатура контрагента
		—   Остатки номенклатуры
		—   Продажа товаров

2.2. Общие модули
Для повторного использования кода созданы общие модули:
*   Работа с документами (содержит процедуру расчета суммы, используемую в документах)
*   Работа с ценой (получение актуальной цены продажи номенклатуры)

2.3 Общие формы
*   Организация (используется для унификации интерфейса)

2.4 Общие макеты
*   Карточка предприятия

2.5 Роли и права пользователей
В конфигурации определены четыре базовые роли:
*   Администратор (обладает полными правами + администрированием данных, единственная роль, которая может менять состав пользователей и настройки)
*   Руководитель (обладает правами чтения всех данных, не может создавать и проводить документы)
*   Менеджер закупок (ведёт номенклатуру и цены, оформляет поступления. Не проводит реализации)
*   Менеджер продаж (может создавать и проводить только документы реализации, не имеет доступа к документам закупок)
